## Usage

```tsx
import { Button } from "@/components/ui/button";

<Button>Save changes</Button>;
```

### Action state

Set `state` to report the action. `loading` lasts until you change it; `success` and `error` hold for 1.5s, then return to the label without changing your prop.

### Composition

`render` swaps the element, and Button's motion and state come with it. Spread the props it receives.

```tsx
<Button nativeButton={false} render={(props) => <div {...props} />}>
    Choose file
</Button>
```

<Callout title="Navigation uses a link element">
    A link rendered through `render` announces as a button. Navigate with `<a href>` or your router's link component, styled with `buttonVariants`.
</Callout>

### Links styled as buttons

`buttonVariants` returns Button's classes for any element, so a link looks like a button and still announces as a link.

```tsx
import { buttonVariants } from "@/components/ui/button";
import Link from "next/link";

<Link href="/pricing" className={buttonVariants({ variant: "secondary", size: "lg" })}>
    See pricing
</Link>;
```

The link takes the surface, hover tint and focus ring. Press and lift stay with Button: a link confirms by navigating. Its touch target is its own height, so use `lg` where touch comes first.

### Icons

An icon without a `size-*` class renders at 16px in every size, the same box as the state indicators, so a state change replaces it in place. Give the icon a `size-*` class to keep another size; Lucide's `size` prop and `h-*`/`w-*` classes are overridden.

## API reference

<ApiTable name="button" />

Button accepts every `<button>` attribute except `onAnimationStart`, `onDrag`, `onDragStart` and `onDragEnd`, which motion claims for its own events.

`buttonVariants({ variant, size })` takes the same `variant` and `size` values, defaults to `primary` and `md`, and returns a class string.

## Motion behavior

Button has no motion props. It is tuned only through `--motion-*` tokens.

| Interaction  | Motion                                                  | Timing                                        |
| ------------ | ------------------------------------------------------- | --------------------------------------------- |
| Press        | Scales from 1 to 0.97                                   | 100ms `ease-out`                              |
| Release      | Returns to 1 with a ~4% overshoot                       | `spring-snappy`, settles in ~250ms            |
| Hover        | Lifts 1px and tints the surface                         | 150ms `ease-in-out`                           |
| Focus        | The ring fades in                                       | 150ms `ease-in-out`                           |
| State change | Label and indicator cross-fade in place                 | 100ms exit, 50ms hold, 150ms entrance (300ms) |
| Error        | The button shakes ±4px for three cycles on `translateX` | 240ms                                         |

Reduced motion and strict mode cut every transition to instant. The spinner keeps turning, slower.

## Accessibility

- The label is the accessible name in every state; the indicators are hidden from assistive technology.
- An icon-only button needs an `aria-label`.
- Button announces nothing on success or error. Report the outcome with a Toast, or a Field message for validation.

| Key               | Action                                            |
| ----------------- | ------------------------------------------------- |
| `Tab`             | Moves focus to the button, skipping disabled ones |
| `Enter` / `Space` | Activates the button                              |
