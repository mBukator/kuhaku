# kuhaku (空白)

The motion-first design system where every interaction is crafted
and every still surface is dignified. Built on Base UI, distributed
like shadcn, opinionated like Apple.

> Pre-release. Nothing here is stable yet.

Monorepo: `apps/docs` (docs site + registry host) · `packages/registry`
(component source) · `packages/cli` (the `kuhaku` CLI) · `packages/tokens`
(the token layer).
